# Font assets

- Bricolage Grotesque — variable font with optical-size, width and weight axes.
- Newsreader — variable regular and italic fonts with optical-size and weight axes.
- JetBrains Mono remains available from the existing project dependency and is reserved for code/JSON.

Bricolage Grotesque and Newsreader are sourced from Google Fonts and distributed under the SIL Open Font License 1.1. The corresponding license texts are included alongside the font files.
